## LoveSpace — prueba local v1

Tabla adaptada al `LoveRitmo.exe` aportado para pruebas en el servidor local.
El paquete conserva la tabla original e incluye instrucciones, offsets,
hashes y resultados de validación. Pasaron 72 casos en emulación aislada;
queda pendiente probarla con Cheat Engine, el juego y el servidor en Windows.
